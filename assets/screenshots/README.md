# Screenshot Checklist

Add only sanitized screenshots that help a recruiter understand the work.

Recommended screenshots:

- Cisco Packet Tracer topology with private or sample addressing
- Wireshark capture using lab-generated traffic
- n8n workflow with credentials and webhook URLs hidden
- Firebase dashboard using sample sensor data
- MATLAB PID simulator interface
- Cybersecurity portfolio reports with personal or company data removed

Before uploading an image, check every corner for API keys, usernames, email addresses, IP addresses, serial numbers, customer records, and internal company information.
