# PID Control System Simulator Using MATLAB

## Overview

This diploma final year project is a MATLAB GUI-based simulator for visualizing proportional, integral, and derivative controller behavior. It allows users to examine step-response and impulse-response characteristics and evaluate controller performance.

## Key Features

- User input for plant and controller transfer functions
- Step-response and impulse-response plots
- Ziegler-Nichols tuning calculations
- Evaluation of rise time, overshoot, settling time, and steady-state error
- Interactive MATLAB GUIDE interface
